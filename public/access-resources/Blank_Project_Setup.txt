วิธีเริ่มไฟล์โครงงานใน Microsoft Access

1. เปิด Microsoft Access แล้วเลือก Blank database
2. ตั้งชื่อไฟล์ Library_รหัสนักเรียน.accdb
3. เลือกตำแหน่งจัดเก็บ แล้วกด Create
4. เปิดไฟล์นี้ต่อเนื่องในสัปดาห์ถัดไป และสำรองไฟล์เป็นประจำ

หมายเหตุ: ไฟล์นี้เป็นคู่มือ ไม่ใช่ฐานข้อมูล .accdb นักเรียนสร้างไฟล์เปล่าได้จาก Microsoft Access ตามขั้นตอนข้างต้น
