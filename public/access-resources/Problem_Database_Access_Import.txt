ใบงานที่ 1 สัปดาห์ที่ 1: สำรวจปัญหาการเก็บข้อมูลแบบตารางเดี่ยว

ไฟล์ประกอบ: Problem_Database.csv
ฐานข้อมูลที่ใช้ทำงานและส่ง: Problem_Database.accdb
ตาราง: tbl_Sales
ข้อมูลจำลองสำหรับฝึก: ลูกค้า 13 คน รวม 29 รายการขาย ลูกค้าทุกคนมีรายการซื้อ 2–3 แถว
ชื่อและเบอร์โทรศัพท์ของลูกค้าแต่ละคนตรงกันทุกแถวก่อนเริ่มทดลอง

ขั้นตอนที่ 1 เตรียมฐานข้อมูลใน Microsoft Access
1. ดาวน์โหลด Problem_Database.csv แล้วเปิด Microsoft Access
2. เลือก Blank database ตั้งชื่อ Problem_Database.accdb แล้วกด Create
3. ไปที่ External Data > New Data Source > From File > Text File
   (บางรุ่นเลือก External Data > Text File)
4. เลือก CSV ที่ดาวน์โหลด และ Import the source data into a new table in the current database
5. เลือก Delimited ตัวคั่น Comma และ First Row Contains Field Names
   ไฟล์ใช้ Unicode UTF-16 LE หากภาษาไทยไม่ถูกต้องให้เลือก Unicode ในตัวเลือกการนำเข้า
6. กำหนดชนิดข้อมูลแต่ละฟิลด์ดังนี้
   Sale_ID: Number (Long Integer) — รหัสการขาย
   Sale_Date: Date/Time — วันที่ขาย เลือกลำดับวันที่ YMD ให้ตรงกับข้อมูลปี-เดือน-วัน
   Product_ID: Short Text — รหัสสินค้า
   Product_Name: Short Text — ชื่อสินค้า
   Price: Currency — ราคาสินค้า
   Customer_ID: Short Text — รหัสลูกค้า
   Customer_Name: Short Text — ชื่อลูกค้า
   Customer_Phone: Short Text — เบอร์โทรศัพท์ ต้องเก็บเป็นข้อความเพื่อคงเลขศูนย์นำหน้า
7. เลือก Choose my own primary key และ Sale_ID ตั้งชื่อตาราง tbl_Sales แล้วกด Finish
8. ตรวจว่ามีข้อมูล 29 แถว ไม่มีข้อผิดพลาดการนำเข้า และเบอร์โทรศัพท์ครบ 10 หลัก

ขั้นตอนที่ 2 สำรวจความซ้ำซ้อน
1. เปิด tbl_Sales ใน Datasheet View
2. สังเกตว่าตารางเดียวรวมข้อมูลการขาย สินค้า และลูกค้าไว้ด้วยกัน
3. กรอง Customer_Name ให้เป็นชื่อของตนเอง จะพบ 2–3 รายการขาย
   หากไม่พบชื่อ ให้เลือกรหัสลูกค้าหนึ่งราย แล้วเปลี่ยน Customer_Name ของรหัสนั้นทุกแถวเป็นชื่อของตนเองก่อนทดลอง
4. จด Sale_ID ของแต่ละแถว และสังเกตชื่อกับเบอร์โทรศัพท์ที่ถูกบันทึกซ้ำ

ขั้นตอนที่ 3 จำลองข้อมูลไม่สอดคล้อง
1. เรียง Sale_ID จากน้อยไปมากสำหรับลูกค้าที่เลือก จดเบอร์เดิมไว้
2. สมมติว่าลูกค้าเปลี่ยนเบอร์ ใช้เบอร์จำลองใหม่ 10 หลักที่ต่างจากเดิม
3. แก้ Customer_Phone เฉพาะแถวแรกของลูกค้ารายนั้น แล้วเลื่อนไปแถวอื่นเพื่อบันทึกข้อมูล
4. คงเบอร์เดิมในแถวที่เหลือ แล้วเปรียบเทียบข้อมูลของ Customer_ID เดียวกัน
5. บันทึกว่าพบเบอร์ใดบ้าง อยู่ที่ Sale_ID ใด และส่งผลต่อการติดต่ออย่างไร

ขั้นตอนที่ 4 บันทึกผลและส่งงาน
กรอกตามผลที่ทดลองจริง ไม่ต้องแก้เบอร์แถวอื่นให้ตรงกันก่อนส่ง เพื่อเก็บหลักฐานการทดลอง
บันทึกฐานข้อมูล ปิดตารางและปิด Access ก่อนส่ง Problem_Database.accdb พร้อมผลวิเคราะห์ผ่านเว็บไซต์บทเรียนตามกำหนด

คำถามสรุป
1. การรวมข้อมูลการขาย สินค้า และลูกค้าในตารางเดียวทำให้ข้อมูลใดซ้ำ เพราะเหตุใด?
2. เมื่อแก้เบอร์เพียงแถวเดียว ข้อมูลของลูกค้าคนเดียวกันไม่สอดคล้องกันอย่างไร?
3. หากมีรายการขายจำนวนมาก การตามแก้ข้อมูลทุกแถวมีข้อจำกัดอย่างไร?
4. การแยกตารางลูกค้า สินค้า และการขาย แล้วเชื่อมด้วยรหัส ช่วยลดปัญหานี้ได้อย่างไร?
